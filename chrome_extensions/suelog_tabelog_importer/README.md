# 食べログのコピー元URLを内部保存する拡張機能

## 初回導入・更新
1. このフォルダーをPC内の固定した場所に保存します。
2. Chromeで `chrome://extensions` を開き、「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダーを選択します。
4. すでに導入済みなら、このフォルダーのファイルを更新し、拡張機能の更新ボタンを押します。
5. 開いている食べログの店舗ページを再読み込みします。

## 普段の操作
今までどおり店舗ページの全選択・コピー・貼り付け、またはエンター送信を行います。
コピー時にそのタブのURLを付加し、吸えログは `import_metadata.source_url` に内部保存します。
URLの公開表示や予約アフィリエイトURLの変更は行いません。
店舗ページ以外や入力欄のコピーには付加しません。拡張機能自身は外部へ自動送信せず、従来の送信操作で吸えログへ送ります。
