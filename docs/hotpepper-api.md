# ホットペッパー公式APIの設定

Renderの本番Webサービス → Environment → Add Environment Variable:

- Key: `HOTPEPPER_API_KEY`
- Value: リクルートWEBサービスから発行されたAPIキー

保存して再デプロイする。キーをソースコード、ログ、公開画面に出さない。
APIエンドポイントはHTTPSで固定済み。他のAPI用環境変数は不要。
既存バリューコマースの広告URLテンプレート・vosは維持する。

管理画面の「ホットペッパー アフィリエイト設定」で公式APIの設定状態を確認し、既存の店舗検索操作を使う。
キーありの場合は公式APIで店舗名検索→電話番号検索。電話番号なしは省略。
店名・住所・登録電話番号を照合し、一意に一致した場合のみ既存ジョブでURLを登録する。
不一致・候補多数・通信失敗は確認対象として残す。既存URLは上書きしない。
キーなしの場合は既存の検索方式を継続する。
